# Báo cáo SV3 ML tuần 1–4

| Tuần | Báo cáo | Nội dung |
|---|---|---|
| 1 | [SV3 ML Week 1 Report](SV3_ML_week1_report.md) | Môi trường, dữ liệu MIT-BIH/PTB-XL, preprocessing, patient split và verification |
| 2 | [SV3 ML Week 2 Report](SV3_ML_week2_report.md) | Baseline CNN, training configuration, kết quả và provenance lịch sử |
| 3 | [SV3 Week 3 confirmed split handoff](../week3_sv2_split_audit.md) | Frozen model, canonical splits, FP32 handoff, ONNX verification và trạng thái acceptance |
| 4 | [SV3 ML Week 4 Review](../SV3_ML_week4_review.md) | All-split tensor profiling, non-monotonicity, parameters, reference reuse và verification |

Các báo cáo tuần 1–2 giữ nguyên nội dung lịch sử. Báo cáo tuần 3 đã được
version control; dùng bản confirmed handoff mới nhất tại link trên. Phần
SV3 offline tuần 4 đã PASS; SV1 execution/timing và SV2 hardware acceptance
là công việc độc lập. [Handoff SV1 tuần 4](../sv3_sv1_week4_handoff.md) ghi
đầy đủ paths và commands để sử dụng deliverables.
